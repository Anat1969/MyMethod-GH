# אפיון: שיטת העבודה שלי

החלטה: נבנית אפליקציה חדשה, כי הכלים שנבדקו אינם מחזיקים את נתוני תהליך הבנייה ואינם משמשים באותו רגע של הוראה ותיעוד.

קהל: ענת, עמיתים ותלמידים. מטרה: ללמד קבלת החלטות בעבודה עם AI, באמצעות הסבר ותיעוד ממשי.
קלט: רעיון, קהל, החלטה, נימוק וראיה בכל שלב. פלט: מסלול מתועד, מצגת, קובץ גיבוי וקישור לשיתוף.
שלוש תשובות ראשונות: איך עוברים מרעיון למוצר; למה בוחרים בכל שלב; מה אפשר ליישם עכשיו.

דפוס מהבנק: ספר שמתעורר, כי שלב נבחר חושף את ההחלטה והופך את הרצף למנגנון ברור.
החידוש: חדר החלטות אישי שמפריד בין החלטה, נימוק וראיה ומציג אותם כתהליך הוראה.

## תרחיש
דף בית → בחירת שלב → הבנת ההחלטה והפרומפט → תיעוד במחברת → רענון → הצגה ושיתוף.
מדד הצלחה: ניתן לתעד החלטה אחת עם נימוק וראיה, לטעון מחדש ולפתוח תמונת מצב במכשיר אחר.
מדד השלמות: מספר שלבים עם שלושת השדות מלאים חלקי שישה. אינו ציון איכות.
